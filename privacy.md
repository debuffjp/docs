# Privacy

## This website

debuff.jp uses **Cloudflare Web Analytics** to count visits and measure page speed. It doesn't use cookies or local storage, and it doesn't track you across sites. It records, in aggregate:

- the page visited and the referring site
- browser, operating system and country, derived from the request
- page-load performance (Core Web Vitals)

We use this to learn which pages help people and which links bring them here. A link from a game's "made with debuff" card includes `?ref=made-with`, so we can count visits from games built with debuff. It carries no information about the player.

The playable demo on the home page runs entirely in your browser and sends nothing anywhere.

## The debuff toolkit

The debuff packages, CLI, dev tools, MCP server and Claude plugin **collect no telemetry**. Games you make with debuff send nothing to us. The dev tools and MCP server only talk to your own local dev server.
